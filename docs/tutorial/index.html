lwfm: how the framework works

A short tour for anyone joining the project: the ideas behind the framework, how its pieces fit together, how it sits on top of PyTorch, and where to add your own work.

How to read these slides. Everything is colour-coded by where it comes from:

nn.Module orange = PyTorch (or torchvision / torchmetrics). You already know these, or can look them up in the PyTorch docs.

ModelNode blue = lwfm, our framework. Defined in this repo, under lwfm/.

In code, comments start with # torch: or # lwfm: for the same reason.
