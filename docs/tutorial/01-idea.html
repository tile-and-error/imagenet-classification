1. The idea

We train a small model (the student) to copy a large, frozen model (the teacher), so the student gets close to the teacher's quality at a fraction of the cost. This is knowledge distillation.

  • We prove the method on ImageNet first, then move to pathology slides (WSIs: whole-slide images). The move should change the data and the teachers, not the code.
  • Every part is swappable: data, teacher(s), student, losses, metrics, where results are saved.

The one rule: PyTorch all the way down

Every object you train or run is an ordinary PyTorch object. Our framework adds wiring (which value goes where) and record-keeping (what happened in a run). It never replaces PyTorch.

You keep usinglwfm adds
nn.Module, nn.Sequential, torch.optim.SGD, nn.CrossEntropyLoss, DataLoader ModelNode, ExecutionGraph, LossBinding, MetricBinding, Evaluator, OutputRouter
Why? A model proven here must later run in TIAToolbox and, eventually, on small hardware. If it is a plain PyTorch module, it can be saved, profiled, exported or wrapped with normal PyTorch tools, without first being pulled out of a framework.
